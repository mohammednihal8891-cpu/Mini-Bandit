# 🛡️ Mini-Bandit CTF

A beginner-friendly Linux Cybersecurity Capture The Flag (CTF) project inspired by OverTheWire Bandit.

## 📌 About

Mini-Bandit is a terminal-based cybersecurity challenge designed for beginners to learn basic Linux and cybersecurity concepts through interactive levels.

The project contains 10 levels. Each level introduces a different cybersecurity or Linux concept, and solving each level unlocks the next one.

## 🎯 Features

- 10 interactive CTF levels
- Linux terminal-based challenges
- Beginner-friendly
- Wrong answers can be retried
- Different cybersecurity concepts in each level
- Final challenge with a calculated code
- Retry support for incorrect answers

## 🧩 Levels

1. Base64 Decoding
2. Linux Commands (ls, grep, cat)
3. File Permissions
4. File Searching using find
5. Hexadecimal Decoding
6. Caesar Cipher
7. File Searching using grep
8. MD5 Hash
9. find + File Permissions
10. Final Calculation
